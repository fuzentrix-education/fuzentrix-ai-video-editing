# videos/

One folder per video: `videos/<short-name>/` (lowercase, hyphens, no spaces), holding the rough cut or raw footage, any screen
recording, and `prompt.md`. Claude adds `edit/` (working files, the review page) and the final `<Title> - Edited.mp4`.

Everything here except this README stays on your machine: video files are never committed.
See [docs/EDITOR-GUIDE.md](../docs/EDITOR-GUIDE.md).
