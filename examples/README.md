# Examples

| Example | Shows |
|---|---|
| `loop-control/edit.yaml` | A full overlay-mode spec for the 15-minute Loop Control rough cut (see the first job in its README) |

What the Loop Control spec covers:
- intro and name card
- agenda
- an analogy staged with props
- definitions and type cards
- a flowchart walk
- a traced code example with an `@phrase` anchor
- code typed to dictation, with notes outside the code
- a summary
- a studio-layer tag for every studio shot

To try one, copy the spec into a video folder's `edit/` and run `bin/fzv ingest`, then `build → validate → render → finish → verify`.
