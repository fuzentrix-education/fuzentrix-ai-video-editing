# Characters and props

**Availability:** Whenever the prompt or content names them. **Used for:** people, vehicles, devices, objects in analogies and stories.

All colours, fonts and timings come from the brand kit (CSS variables `--fz-*`), so this family looks the same in every video and adapts to the brand.

## Look

- Only assets from global/props (manifest.yaml); flat style for Core, line style for Sketch.
- Assets are coloured with brand variables only, so they recolour per brand; skin, hair and glass use fixed neutrals.
- Staged on a ground line (`road`, `desk`) inside the free area; never over the instructor.

## Motion

- Fixed vocabulary: enter (pop, slide, fade), idle (gentle bob), move (along a path, eased, optional speed lines), react (shake, pulse, tick, cross), exit.

Templates: see `global/templates/props/`.
