# Data Storytelling

**Availability:** Content-driven. **Used for:** counts, comparisons, growth, Big-O, query results.

All colours, fonts and timings come from the brand kit (CSS variables `--fz-*`), so this family looks the same in every video and adapts to the brand.

## Look

- Flat bars and lines in brand colours (`--fz-accent`, semantic colours for good/bad).
- Values in Outfit 800; labels in Inter 600 `--fz-text2`.

## Motion

- Bars grow from the baseline (scaleY, 0.6 s) as each value is said.
- Counters count up over ~1.2 s; curves draw on over ~1.2 s.

Templates: see `global/templates/data/`.
